# 智趣学堂 · 小学生全学科游戏化闯关学习平台
> 基于 **React 18 + Vite** 开发的中国大陆小学生全学科沉浸式学习网站，深度完整覆盖**人教版小学三年级数学全册 17 个单元核心知识点**。

---

## 🚀 快速启动指南

### 1. 环境准备
确保您的电脑上已安装 [Node.js](https://nodejs.org/)（推荐 Node 18+ 或更高版本）。

### 2. 进入项目目录
在终端（CMD、PowerShell 或 VSCode 终端）中进入本项目所在目录：
```powershell
cd e:\WorkSpace-study\learning
```

### 3. 安装依赖（首次运行或依赖变动时）
```powershell
npm install
```

### 4. 启动本地开发服务
```powershell
npm run dev
```
启动成功后，终端将输出访问地址，在浏览器中打开即可体验：
👉 **http://localhost:5174/** （若端口被占用会自动顺延为 5175 等，具体以终端提示为准）

## 🌟 核心特色与功能

1. **教材知识点全覆盖**：
   - **三年级上册 9 个单元**：时分秒、万以内加减法（一）、测量、万以内加减法（二）、倍的认识、多位数乘一位数、长方形和正方形、分数的初步认识、数学广角（集合）。
   - **三年级下册 8 个单元**：位置与方向（一）、除数是一位数的除法、复式统计表、两位数乘两位数、面积、年·月·日、小数的初步认识、数学广角（搭配二）。
2. **四阶闭环闯关**：
   - **【魔法学堂】**：名师图文导学、记忆顺口溜、核心公式、智能中文语音伴读。
   - **【具象工坊】**：高自由度动手互动教具（齿轮联动表盘、分数披萨切分机、周长红线与面积网格板、八方向小镇指南针、天平与度量尺等）。
   - **【趣味挑战】**：3 颗心血条答题对决、连击金币、答错即时点拨并收录进错题本。
   - **【领主 Boss 战】**：击败单元大魔王，赢取 3 星战绩与岛屿专属黄金勋章。
3. **伴学与督学工具**：
   - **错题复习本**：支持针对薄弱知识点“一键立即重练”，做对自动消除。
   - **荣誉殿堂**：17 枚岛屿黄金勋章陈列墙。
   - **学情报告**：答题准确率、Boss 击败数与名师诊断建议。
   - **伴学灵宠**：右下角“算术小神龙”常驻互动与答题打气。
4. **离线即用**：
   - 纯前端架构，无需后端或复杂数据库配置，进度通过 `localStorage` 自动存盘；内置纯 Web Audio API 8-bit 童趣合成音效。
