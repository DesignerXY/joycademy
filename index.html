🚀 免费平台一键部署指南

🐙 方案一：GitHub Pages (全自动化流水线，已内置)

代码库已内置 .github/workflows/deploy.yml。只需将本工程推送到 GitHub 仓库的 main 分支，在仓库设置 Settings -> Pages -> Build and deployment Source 选择 GitHub Actions，每次 push 就会全自动构建并上线！

⚡ 方案二：Cloudflare Pages / Workers (零成本全球边缘极速)

方式 A (Git 自动部署)：在 Cloudflare Dashboard 创建 Pages 项目并绑定本仓库，构建命令填 npm run build，输出目录填 dist 即可。
方式 B (命令行直发)：已内置 wrangler.toml，终端执行以下命令即可直发 Cloudflare：

npm run deploy:cf

🌐 方案三：Vercel / Netlify 等平台

连接 Git 仓库后选择 Vite 模板，Build Command 填 npm run build，Publish Directory 填 dist 即可零配置部署。全站所有资源均采用相对路径（base: './'），无需硬编码任何域名！
